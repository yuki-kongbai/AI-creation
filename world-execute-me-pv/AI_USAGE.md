# AI 使用情况

Mili 的[官方指引](https://projectmili.com/copyright-guidelines)要求
AI 同人内容明确标注，所以这里如实列出。

## 这张片子

| 用途 | 工具 | 说明 |
|---|---|---|
| **写代码** | DeepSeek Harness（`deepseek-flash`） | 本仓库根目录下的代码由 AI 在会话中编写。**总体方案、审美取舍、逐轮审片由作者完成** |
| **画面** | Python + Pillow | **逐帧程序化渲染**。点云、文字、面板、内存条、崩坏效果全是代码画的 —— **没有使用任何图像生成模型** |
| **左窗** | 本机 Edge + `playwright-core` | 渲染**真实的 DSH 前端 HTML** 后截帧，不是画出来的 |
| **歌词对齐** | 上游逐词时间 + 自写动态规划 | 词长签名对齐。**本机没有跑 Demucs / Whisper / MMS**，直接用了上游对齐结果 |
| **音频分析** | 本机特征提取（`audio.py`） | 只做能量/频带分析驱动画面参数，**不生成声音** |
| **字体** | Windows 自带 | Consolas / 微软雅黑 / Segoe UI Symbol / Arial Black，未使用生成模型 |
| **音乐** | 无 | 用户自备，不参与生成 |

## 结论

- **代码**：AI 编写。
- **画面**：全部由代码渲染，**无生成式图像**。
- **音频**：用户自备的版权音乐，本项目不生成、不分发。

对外说明时请按上面这两条写，不要简化成"AI 做的片子"，
也不要写成"全部画面均非 AI"。
